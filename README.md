# echo636.github.io

网站：https://echo636.github.io

当前网页仅显示 GitHub 个人主页链接：https://github.com/echo636 。

编辑根目录的 `index.html` 即可更改网页。保存到 `master` 分支后，GitHub Pages 会自动发布。

发布设置：Settings → Pages → Deploy from a branch → master → /(root)。

目前没有使用模板或构建依赖。之前准备的 Academic Pages 版本保存在 Git 历史中，需要时可以恢复；其许可证保留在 LICENSE 中。模板附带的三个工作流均已禁用。
